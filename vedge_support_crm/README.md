# Vedge Nutrition Customer Support Inquiry Library

This is a standalone, local reference application. Open `index.html` in a browser.

## Sections
- Inquiry & Answer Library: earlier inquiry examples plus question/answer excerpts paired from the uploaded Front export.
- Resolution Steps: recommended platform-specific checks for each inquiry type.
- Reply Builder: editable response area using a historical answer excerpt.
- Tool Guide: role of Front, Shopify, ShipMonk and Loop.
- Confidential Reference: customer identifiers and conversation metadata kept separate from the inquiry/answer library.

## Important limitations
- The Front export contains truncated message extracts. Some inquiry/answer pairs may be incomplete or paired to a later reply in the same ticket. Always open the complete conversation in Front before relying on an excerpt.
- These are examples from historical support conversations, not verified current company policy.
- This app does not connect to Front, Shopify, ShipMonk or Loop and does not send emails or make changes.
- The Confidential Reference tab contains customer-identifying information. Keep the entire folder private. Do not upload it to a public GitHub repository or share it outside approved Vedge systems.
