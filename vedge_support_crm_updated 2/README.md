# Vedge Nutrition Support CRM

Open `index.html` in a modern browser.

## Workspace sections
- Inquiry Library: 59 examples from the linked customer history workbook.
- Resolution Workflows: category-level suggested SOPs.
- Reply Builder: edit a historical response before use.
- Tool Guide: Shopify, ShipMonk, Loop Subscriptions, and Front.
- Case Notes: local case notes and CSV export.
- Quality & Escalations: verification and escalation guardrails.
- Live Case Workspace: guided intake, platform investigation fields, task checklist, response draft, copy, and TXT case-summary export.
- New Message Export: inquiry/answer examples parsed from the Front message export.
- Confidential Reference: customer identifiers and ticket metadata separated from support knowledge.

## Important limitations and privacy
This is a standalone local reference app. It does not connect to Shopify, ShipMonk, Loop, or Front, does not change orders/subscriptions/refunds, and does not send emails. The Live Case Workspace creates drafts from what the operator enters; it does not independently verify facts. Historical answers and extracted message snippets are not guaranteed current policies. Verify all actions and current Vedge policy in the official systems before replying.

The confidential tab is only an organizational separation, not encryption or access control. Keep the folder private, do not publish it to a public GitHub repository or public hosting, and follow Vedge's data protection and retention rules. Avoid entering unnecessary customer personal data, payment details, health information, or credentials. Use approved company systems for real customer records.
